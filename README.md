# DSP_Processor_final
32 bit DSP Processor with MAC Optimization and SIMD Extensions

The main focus of the project is implementing **SIMD and MAC operations**, where multiple data values can be processed in parallel.

### Features
- Verilog RTL design
- SIMD operations
- MAC (Multiply-Accumulate) unit
- ALU
- Control logic
- Clock and reset support
- Simulation using Xilinx Vivado

### Tools Used
- Verilog HDL
- Xilinx Vivado
- XSim

### About the Project

I am building this project to improve my understanding of **RTL design, digital logic, and DSP hardware architecture**. The design is being developed and tested block by block before integrating everything into the complete processor.

More features and verification will be added as the project develops.
